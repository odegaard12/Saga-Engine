# Playable game templates v1

This pass keeps SAGA focused on templates that can be played with the current runtime/offline foundation.

## Rule

Public/admin mission templates must only use games that are playable now:

- GPS proximity / signal lock.
- Bearing/compass lock.
- QR collectible, QR key, clue card and bonus QR.
- Existing offline inventory/requirement flow.

Templates should not depend on planned games such as manual password, photo completion, sequence validation or team relay until those flows are fully implemented end-to-end.

## Current curated templates

- Ruta QR con llave.
- Ruta de pistas QR.
- Escape QR corto.
- Gymkhana familiar.

## Deferred until implemented

- Photo completion as a node completion method.
- Manual password/code validation.
- Sequence puzzle validation.
- Team/asymmetric relay completion.
